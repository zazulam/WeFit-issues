# Contributing to WeFit

Thank you for your interest in contributing to WeFit! This repository serves as the public issue tracker for the WeFit application.

## How Can I Contribute?

### Reporting Bugs

Before creating a bug report, please check if the issue has already been reported. If it has and the issue is still open, add a comment to the existing issue instead of opening a new one.

When creating a bug report:
- Use a clear and descriptive title
- Provide detailed steps to reproduce the issue
- Describe the expected behavior and what actually happened
- Include screenshots or videos if applicable
- Specify your platform (iOS, Android, Web) and app version

### Suggesting Features

We welcome feature suggestions! When submitting a feature request:
- Use a clear and descriptive title
- Provide a detailed description of the proposed feature
- Explain why this feature would be useful to most WeFit users
- Include examples or mockups if possible

### Asking Questions

Have a question? Feel free to open a question issue! We're here to help you get the most out of WeFit.

## Issue Guidelines

### Search First
Before creating a new issue, please search existing issues to avoid duplicates.

### Use Issue Templates
We provide templates for different types of issues. Please use the appropriate template when creating an issue.

### Be Respectful
Remember to be respectful and constructive in all interactions. See our [Code of Conduct](CODE_OF_CONDUCT.md).

### Provide Context
The more information you provide, the better we can help. Include:
- Device and OS information
- App version
- Steps to reproduce
- Screenshots or videos
- Any error messages

### Security Issues
**Do not** open public issues for security vulnerabilities. Please report them privately through [GitHub Security](https://github.com/zazulam/WeFit-issues/security).

## Issue Labels

We use labels to organize and prioritize issues:

- `bug` - Something isn't working as expected
- `enhancement` - New feature or request
- `documentation` - Improvements or additions to documentation
- `question` - Questions about using WeFit
- `triage` - Needs review from maintainers
- `wontfix` - This will not be worked on
- `duplicate` - This issue already exists
- `help wanted` - Extra attention is needed
- `good first issue` - Good for newcomers

## Response Times

We aim to:
- Acknowledge new issues within 1-3 business days
- Provide initial feedback within 1 week
- Keep you updated on progress

Please note that as this is for a private application, we may not be able to share all implementation details or timelines.

## Questions?

If you have questions about contributing, feel free to open a question issue!

Thank you for helping make WeFit better! 💪
